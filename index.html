How to use the ORM Packer

  1. Choose a target — Unreal/Godot/glTF ORM, Unity HDRP Mask Map, Unity URP/Built-in Metallic, or Custom. The channels relabel themselves.
  2. Load your maps — drop all of them at once anywhere on the page; they are matched by file name suffix (_AO, _Occlusion, _Roughness, _Metallic, _Smoothness, _Gloss, _Height, _Detail…). You can also click Load Map, drag a file onto a channel, or hover a channel and paste with Ctrl+V.
  3. Missing a map? Use a solid value instead (e.g. Metallic = 0 for non-metals, Occlusion = 255 for no occlusion).
  4. Roughness ↔ Smoothness — enable Invert. It is switched on automatically when a Roughness file lands in a Smoothness channel (and vice versa).
  5. Pick the output size (longest side — non-square textures keep their aspect ratio) and download. The PNG is written losslessly, pixel-exact, including the alpha channel.

Switching the target re-routes the maps you already loaded. To convert a texture between formats (e.g. Unreal ORM → Unity Mask Map), load it in the Splitter, press Send all to packer, then change the target.

Importing the packed texture

Unreal Engine

Import the PNG, uncheck sRGB and set Compression Settings to Masks (no sRGB). In the material connect R → Ambient Occlusion, G → Roughness, B → Metallic.

Unity

In the texture import settings uncheck sRGB (Color Texture). HDRP: assign it to the Mask Map slot. URP / Built-in: assign it to Metallic and set Smoothness Source to Metallic Alpha.

Godot

Use an ORMMaterial3D and assign the texture to its ORM slot.

Blender

In the Image Texture node set Color Space to Non-Color, add a Separate Color node and connect G → Roughness and B → Metallic. R (occlusion) is used by the glTF exporter through the glTF Material Output group.

FAQ

What is an ORM texture?

An ORM texture stores three grayscale PBR maps in one image: Ambient Occlusion in the red channel, Roughness in the green channel and Metallic in the blue channel. It saves texture memory and samplers in game engines.

How do I turn a Roughness map into Smoothness?

Smoothness is the inverse of roughness (255 minus the value). Enable Invert on the channel. When a file named like _Roughness is loaded into a Smoothness channel, the tool inverts it automatically.

Are my textures uploaded to a server?

No. All processing happens locally in your browser. Your images never leave your computer.

Why does my packed texture look wrong in the engine?

Packed masks contain linear data, not color. Disable sRGB in Unreal and Unity import settings and set the Color Space to Non-Color in Blender.

Which resize filter should I use?

Smooth averages pixels when reducing size (and interpolates when enlarging), which avoids noise and aliasing in roughness and occlusion. Use Nearest only for pixel art or masks that must keep hard edges.

Does it support 16-bit textures?

Browsers decode images at 8 bits per channel, so the output is an 8-bit PNG. That is the standard precision for packed masks in real-time engines.
