What is an ORM texture?

An ORM texture (also called an ORM map or OcclusionRoughnessMetallic texture) is a single image that stores three grayscale PBR maps, one in each color channel:

  • R — Ambient Occlusion (O): how much ambient light reaches each point. White = fully lit, dark = occluded crevices.
  • G — Roughness (R): how rough or glossy the surface is. Black = mirror-like, white = matte.
  • B — Metallic (M): whether the surface is metal. White = metal, black = non-metal (dielectric).

Because each of these maps only needs one channel, packing them together uses one texture instead of three: less memory, fewer texture samplers and fewer files to manage. That is why the ORM layout is the standard in Unreal Engine, Godot and the glTF format used by Blender, Sketchfab and the web. Substance Painter exports it as OcclusionRoughnessMetallic. An ORM texture looks oddly colored when you open it in an image viewer: that is normal, it is data, not a picture.

Unity uses different packed layouts (the HDRP Mask Map and the URP Metallic-Smoothness map), which this tool can also create, or convert from an ORM texture.

How to use the ORM Packer

  1. Choose a target — Unreal/Godot/glTF ORM, Unity HDRP Mask Map, Unity URP/Built-in Metallic, or Custom. The channels relabel themselves.
  2. Load your maps — drop all of them at once anywhere on the page; they are matched by file name suffix (_AO, _Occlusion, _Roughness, _Metallic, _Smoothness, _Gloss, _Height, _Detail…). You can also click a channel square, drag a file onto it, or hover a channel and paste with Ctrl+V.
  3. Missing a map? Use a solid value instead (e.g. Metallic = 0 for non-metals, Occlusion = 255 for no occlusion).
  4. Roughness ↔ Smoothness — enable Invert. It is switched on automatically when a Roughness file lands in a Smoothness channel (and vice versa).
  5. Adjust a channel — every channel has Invert and Levels (output min/max), e.g. to make a roughness map less glossy by raising its minimum. The square shows the result.
  6. Pick the output size (longest side — non-square textures keep their aspect ratio) and download. The PNG is written losslessly, pixel-exact, including the alpha channel.

Switching the target re-routes the maps you already loaded. To convert a texture between formats (e.g. Unreal ORM → Unity Mask Map), load it in the Splitter, press Send all to packer, then change the target.

Importing the packed texture

Unreal Engine

Import the PNG, uncheck sRGB and set Compression Settings to Masks (no sRGB). In the material connect R → Ambient Occlusion, G → Roughness, B → Metallic.

Unity

In the texture import settings uncheck sRGB (Color Texture). HDRP: assign it to the Mask Map slot. URP / Built-in: assign it to Metallic and set Smoothness Source to Metallic Alpha.

Godot

Use an ORMMaterial3D and assign the texture to its ORM slot.

Blender

See How to use ORM textures in Blender below.

How to use ORM textures in Blender

  1. Add an Image Texture node with your ORM texture and set its Color Space to Non-Color. With sRGB the roughness and metallic values come out wrong.
  2. Add a Separate Color node (mode RGB; called Separate RGB in Blender 3.2 and older) and connect the image Color output to it.
  3. Connect Green → Roughness and Blue → Metallic of the Principled BSDF.
  4. Red (ambient occlusion) has no input on the Principled BSDF: Cycles and EEVEE compute occlusion themselves. If you export to glTF / GLB, connect Red to the Occlusion input of a glTF Material Output node so the exporter keeps it.

FAQ

What is an ORM texture?

An ORM texture stores three grayscale PBR maps in one image: Ambient Occlusion in the red channel, Roughness in the green channel and Metallic in the blue channel. It saves texture memory and samplers in game engines.

How do I turn a Roughness map into Smoothness?

Smoothness is the inverse of roughness (255 minus the value). Enable Invert on the channel. When a file named like _Roughness is loaded into a Smoothness channel, the tool inverts it automatically.

Are my textures uploaded to a server?

No. All processing happens locally in your browser. Your images never leave your computer.

Why does my packed texture look wrong in the engine?

Packed masks contain linear data, not color. Disable sRGB in Unreal and Unity import settings and set the Color Space to Non-Color in Blender.

How do I use an ORM texture in Blender?

Load it in an Image Texture node with Color Space set to Non-Color, add a Separate Color node, and connect Green to Roughness and Blue to Metallic of the Principled BSDF. Red (ambient occlusion) is not an input of the Principled BSDF; connect it to the Occlusion input of the glTF Material Output node if you export to glTF.

Can I pack textures without Photoshop or Substance?

Yes. This free online texture channel packer combines grayscale maps into the R, G, B and A channels of one PNG directly in the browser, and can also split a packed texture back into separate maps.

Which resize filter should I use?

Smooth averages pixels when reducing size (and interpolates when enlarging), which avoids noise and aliasing in roughness and occlusion. Use Nearest only for pixel art or masks that must keep hard edges.

Does it support 16-bit textures?

Browsers decode images at 8 bits per channel, so the output is an 8-bit PNG. That is the standard precision for packed masks in real-time engines.
